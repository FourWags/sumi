# Sumi source branch

This branch contains the tested keyboard source and source-only audit repairs. See [SOURCE-SETUP.md](SOURCE-SETUP.md) before building: binary assets are restored from the recorded source archive and are not tracked here.

The [main branch](https://github.com/FourWags/sumi/tree/main) remains the release index. APKs and corresponding release source archives stay attached to their existing releases. This source commit does not publish an APK or update a phone.
