# Sumi

Offline English-US Android keyboard for Android10 and newer.

Download **sumi.apk** from [Latest release](https://github.com/FourWags/sumi/releases/latest), or add this repository in Obtainium: **https://github.com/FourWags/sumi**. APK filter: `^sumi\.apk$`.

Sumi is an independent installation: `dev.fourwags.sumi.inputmethod.latin`. Existing apps and their settings are not removed or migrated. It starts with fresh settings and an empty personal-media collection.

No Internet permission, analytics, advertising, runtime downloads or typed-text persistence. Personal imported GIFs/images remain in private on-phone no-backup storage and are never release assets. Keep originals before uninstalling or clearing data.

**Personal preview**, not production/store qualification. Latest is an update-discovery designation. Read the release's CHECKS.txt for actual tests, warnings, signing status and untested areas.
